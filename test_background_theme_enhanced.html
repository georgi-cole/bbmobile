API Documentation

Available methods:

  • window.BackgroundTheme.getCurrent() - Get current theme
  • window.game.BackgroundTheme.getCurrent() - Get current theme (alias)
  • window.BackgroundTheme.manualOverride('sunset') - Set theme manually
  • window.BackgroundTheme.setAdaptive(true/false) - Toggle adaptive backgrounds
  • window.BackgroundTheme.updateTheme(true) - Force theme update
