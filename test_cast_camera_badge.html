Cast Editor Camera Badge - Implementation Demo

Implementation Summary: This page demonstrates the new camera badge overlay on the cast avatar preview, improved styling, and responsive layout enhancements.

✓ Completed Features

  • Camera badge overlay (36px circular) on lower-right corner of avatar
  • Badge shows on hover/tap with ripple effect
  • High-contrast badge design (dark background, white border, camera icon)
  • Badge positioned inside .cast-avatar-upload without affecting layout
  • Click on badge or avatar triggers #castPhotoFile input
  • Badge visible for all avatars to allow custom photo uploads
  • Name input maxlength=32 with shortenName algorithm applied
  • Tooltip with full name on roster chip (title attribute)
  • Age input: numeric only, two-digit max, displays ∞ for >99
  • Age >99 stores Infinity in p.meta.age
  • Improved input styling: min-height 44px, better padding, border radius
  • Focus rings on inputs (blue glow on focus)
  • Inner shadows for depth on inputs
  • Name/Age/Sex row layout: single row on wide screens (>700px)
  • Responsive stacking on narrow screens (≤700px)
