🔧 Social Phase Halt Fix - Verification

🐛 Bug Description

The social phase flow was completely broken:

  1. Summary showed twice (after user clicked OK)
  2. Timer continued running after phase should end
  3. Game halted and never advanced to nominations

✅ Fix Applied

  • Simplified onDone(): Removed complex fallback logic, single summary path
  • Fixed OK handler: Removed timer resume, moved callback BEFORE animation
  • Fixed handleSocialPhaseExit(): Removed premature flag resets
  • Proper guard management: Flags only reset at phase START, not during exit

📝 Manual Verification Steps

Follow these steps to verify the fix:

  1. Open the console (F12) to monitor logs
  2. Load the game and start a new game
  3. Skip to social intermission phase (or wait for it)
  4. Let the timer run out WITHOUT doing any actions
  5. Expected: Summary shows ONCE, click OK → advances to nominations immediately
  6. Verify: No duplicate summary, no timer continuation, game advances properly
