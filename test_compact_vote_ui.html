Compact Vote UI Test - Nav Arrows & Avatar Reflow

  • Avatar Reflow: Selected avatar grows via CSS variable (no transform scale)
  • No Title Overlap: Avatar growth pushes content down, doesn't overlap title
  • Stage Scrolling: Stage area scrolls if content exceeds max-height
  • CTA Pinned to Bottom: CTA row pinned to bottom of panel with margin-top: auto
  • Smaller Evict Button: Evict button is smaller (width: min(240px, 70%)) to save vertical space
  • Full Scrim Coverage: Scrim covers entire TV viewport, no background peeking on right

  • CTA row has 3 columns: left arrow, Evict button, right arrow
  • Arrows are always present (never removed from DOM)

  • Selected avatar grows smoothly via width/height change
