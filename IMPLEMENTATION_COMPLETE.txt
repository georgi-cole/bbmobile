KEY IMPLEMENTATION DETAILS
================================================================================

State Variable: game.__twistBadgeShown
  • false = Badge hidden (before modal)
  • true = Badge allowed (after modal)
  • Reset to false each week in decideForWeek()
  • Set to true after modal completes

Flow:
  1. decideForWeek() sets __twistBadgeShown = false
  2. updateTwistBadge() checks flag, keeps badge hidden
  3. Modal shows and completes
  4. showTwistAnnouncementIfNeeded() sets __twistBadgeShown = true
  5. updateHud() triggers updateTwistBadge()
  6. Badge now visible because both twist active AND flag true

Integration:
  • updateHud() at line 889 calls TV.updateTwistBadge()
  • Called from multiple places (phase changes, HUD updates)
  • Badge timing now controlled by modal completion
