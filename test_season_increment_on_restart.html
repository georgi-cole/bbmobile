🎯 Season Increment on Restart - Validation Tests

Test Summary

This test verifies that the season increments correctly when restarting after game completion

Test Setup

These tests verify the localStorage keys and ProfileService integration:

  • bb.lastGameCompleted - marks when a game is completed
  • bb.lastGameCompletedProfileId - stores the profile ID that completed the game

Test 1: Finale Marks Game as Completed

Verifies that showFinaleCinematic() sets the completion flags in localStorage.

Test 2: ProfileService Checks Completion on Profile Selection

Verifies that setCurrentProfile() increments season when a completed game is detected.

Test 3: Different Profile Does Not Increment

Verifies that season does NOT increment when a different profile is selected after game completion.

Test 4: Guest Mode Does Not Increment

Verifies that season does NOT increment in guest mode.

Test 5: Completion Flags Are Cleared After Increment

Verifies that completion flags are cleared after season increment to prevent double-increment.

Integration Test: Full Flow

Runs the complete flow: game completion → restart → profile selection → season increment.
