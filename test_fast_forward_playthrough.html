⏩ Fast-Forward Play-Through Window Test

This test verifies that fast-forward mode enforces a minimum compressed "play-through window" so card sequences remain perceptible rather than instant.

Test Scenario

Simulates a phase with 6 card callbacks, each with an original duration of 2000ms.

  • Normal mode: Total time ≈ 12000ms (12 seconds)
  • FFWD mode: Total time should be between 1500ms and 2880ms (enforced play-through window based on config)
