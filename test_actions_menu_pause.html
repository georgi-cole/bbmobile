Manual Test Instructions

  1. Start the timer by clicking "Start Timer"
  2. Click the Actions menu button (⋮) to open the menu
  3. Verify that:
    • Pause Status shows "Game Paused"
    • Open Modals includes "modal:actions"
    • isPaused() shows "true"
    • Timer stops incrementing
    • Console shows "[ActionMenu] Paused game for Actions menu"
  4. Close the menu by clicking the backdrop or pressing Escape
  5. Verify that:
    • Pause Status shows "Game Running"
    • Open Modals is empty
    • isPaused() shows "false"
    • Timer resumes incrementing
    • Console shows "[ActionMenu] Resumed game after Actions menu closed"
  6. Click "Run Automated Tests" to verify programmatically
