Test Instructions

This page demonstrates the enhanced juror voting overlay with animated audience messages and quick-vote functionality.

  • Click "Show Overlay" to open the fullscreen voting experience
  • Watch SMS-like audience messages and floating emojis animate in the background
  • Use the Quick Vote input to type a player name and send a visual vote
  • Valid names: Alex, Jordan, Taylor, Morgan (case-insensitive)
  • Valid votes trigger avatar flash effects and add custom messages
  • Invalid names show inline error messages with suggestions
  • Close overlay with the × button, Escape key, or "Hide Overlay" button
  • Test keyboard navigation and screen reader accessibility

Features Demonstrated

  • Fullscreen modal overlay with dimmed background and backdrop blur
  • Animated SMS-style audience messages flowing vertically
  • Floating emoji sprites with gentle drift animations
  • Quick-vote input with player name validation
  • Visual feedback: avatar flash and pulse effects on valid votes
  • Custom audience messages when you vote
  • Accessible keyboard navigation (Tab, Shift+Tab, Escape)
  • ARIA attributes for screen readers

  • Reduced motion support for accessibility preferences
