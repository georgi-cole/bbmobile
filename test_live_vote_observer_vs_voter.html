✅ Acceptance Criteria

  • Eligible voters see LiveVoteOverlay directly (no pre-vote modal)
  • Nominated players and HOH (without tie-break) see "You are observing this vote"
  • Only one layer (overlay/rollout/lv2) visible at a time
  • CTAs are 48px minimum and stack properly on mobile
  • No clipped, hidden, or overlapped content
  • Panel visibility restored after vote submission

🧪 Test Scenarios

  • Scenario 1: Eligible voter sees overlay directly → vote → rollout shows → panel restored
  • Scenario 2: Nominated observer sees "observing" message → no vote UI → diary room only
  • Scenario 3: HOH (no tie) sees "observing" message → no vote UI
  • Scenario 4: Mobile viewport → CTA buttons are 48px+ and stack properly
  • Scenario 5: Cleanup called → all overlays removed → panel visible
