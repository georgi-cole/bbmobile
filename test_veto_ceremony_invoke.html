🔍 Veto Ceremony Invocation Test

Purpose

This test verifies that the veto ceremony decision prompt appears when a human player wins the Power of Veto. The fix removes the callback from setPhase to prevent premature finalization.

What to Look For

  • ✓ Console logs show: [veto] POV Winner determined
  • ✓ Console logs show: [veto] handlePostVetoReveal with alive count
  • ✓ Console logs show: [veto] Starting veto ceremony
  • ✓ Console logs show: [veto] startVetoCeremony with holder/twist/nominees
  • ✓ Console logs show: [veto] Rendering POV use decision
  • ✓ Console logs show: [veto] Decision resolved (after user clicks)
  • ✓ setPhase called WITHOUT finalizeCeremony callback
  • ✓ Idempotent guard prevents duplicate starts

Instructions

  1. Open the main game (index.html) in a new tab
  2. Start a new game with a human player
  3. Play through until the veto competition phase
  4. Make sure the human player wins the veto competition
  5. Watch the console (F12) for the logging sequence
  6. Verify the decision prompt appears and waits for user input
  7. Return to this tab to review the captured logs below

Expected Behavior

✓ CORRECT: After veto competition, you see:
  • Intro card: "POV Holder will decide..."
  • Decision prompt: "Use Power of Veto?" with YES/NO buttons
  • Prompt waits for your click
  • Console shows all logging steps
✗ BUG (before fix): After veto competition:
  • Phase advances to veto_ceremony
  • Music stops but no UI appears
  • Ceremony auto-proceeds as if veto not used
  • Player cannot make a decision
