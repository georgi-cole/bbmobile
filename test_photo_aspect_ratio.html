Technical Summary

What Changed?

  • Before: Images had border-radius: 50% applied directly
  • After: Images are wrapped in container divs with overflow: hidden and border-radius: 50%
  • Result: Proper circular clipping regardless of source image aspect ratio

Files Modified:

  • js/eviction.js - showDiaryRoomWithAvatars function (lines 324-388)
  • js/results-popup.js - Winner and runner-up avatar rendering (lines 198-320)

CSS Properties Used:

/* Container */
.avatar-container {
  width: 88px;
  height: 88px;
  border-radius: 50%;
  overflow: hidden;  /* Key property! */
  border: 3px solid #7cffad;
  flex-shrink: 0;
}

/* Image inside */
.avatar-container img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
}
