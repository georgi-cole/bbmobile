This demonstrates how the timer behaves when FFWD is activated.

Scenario 1: Start phase with 30 seconds

Expected behavior: Timer starts at 00:30 and counts down normally. When FFWD is clicked, timer compresses to ~00:01-00:02 and phase ends quickly.

Scenario 2: Activate FFWD with 10 seconds remaining

Expected behavior: Timer at 00:10, when FFWD clicked, compresses to 00:01 and phase ends.

00:10

How the FFWD Timer Compression Works

1. Phase starts with normal timer countdown (1 second per second)
2. User clicks ⏩ FFWD button
3. activateFastForward() is called
4. Remaining time is compressed: remainingTime * 0.1 (10x speed)
5. Minimum window enforced: max(compressed, 1500ms)
6. Timer shows 00:01 or 00:02 remaining
7. Phase ends after minimum window
8. Cards and animations are also accelerated during this time

Example Calculations:

30s remaining: 30000ms * 0.1 = 3000ms → enforced to 1500ms → shows 00:01-00:02
10s remaining: 10000ms * 0.1 = 1000ms → enforced to 1500ms → shows 00:01-00:02
5s remaining: 5000ms * 0.1 = 500ms → enforced to 1500ms → shows 00:01-00:02
2s remaining: 2000ms * 0.1 = 200ms → enforced to 1500ms → shows 00:01-00:02
