🐛 Double Summary Card Bug - Fix Verification

Bug Description

Previously, when a player spent all social energy:

  1. Summary card #1 appeared immediately (via fast-advance) ✅
  2. User clicks OK → card disappears
  3. After 30 seconds, summary card #2 appeared ❌ BUG

Root Cause: Two code paths both showing summaries:

  • Path A: scheduleFastAdvanceFallback() showed its own summary
  • Path B: 30-second timer's onDone() callback also showed a summary

Fix Implementation

The fix ensures only ONE code path shows the summary:

  1. scheduleFastAdvanceFallback(): Now only shortens the timer (no summary)
  2. onSocialPhaseEnd(): Removed showSummaryPanel() call
  3. onDone() in social.js: Sole authority for showing summary

Code Changes

// scheduleFastAdvanceFallback() - NEW implementation
function scheduleFastAdvanceFallback(delayMs = 800) {
  // Force phase timer to expire almost immediately
  setTimeout(() => {
    const now = Date.now();
    g.endAt = now + 100;        // Shorten timer
    g.phaseEndsAt = now + 100;  // Trigger onDone()
    global.checkPhaseTimer();
  }, delayMs);
  // NO summary shown here anymore!
}

// onSocialPhaseEnd() - UPDATED
function onSocialPhaseEnd() {
  // ... cleanup logic ...
  const summary = generatePhaseSummary();
  exportSessionLog(summary);
  logToConsole(summary);
  // showSummaryPanel(summary); ← REMOVED!
}

// onDone() in social.js - UNCHANGED (already correct)
const onDone = async () => {
  // Store callback first
  global.game.__socialPhaseAdvanceCallback = advanceToNextPhase;
  
  // Call cleanup (no summary)

  // Generate and show summary (ONLY place)
  const summary = global.SocialManeuvers.generatePhaseSummary();
  global.SocialManeuvers.showSummaryPanel(summary);  ← ONLY call
};
