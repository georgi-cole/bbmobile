🎬 Final 4 Voting UI Modernization Demo

Overview

This demo showcases the modernized Final 4 voting experience with two key improvements:

  1. POV Holder Fullscreen Voting: Modern fullscreen overlay with "Cast Your Sole Vote" title
  2. Nominee Plea System: Nominees can present pleas to influence the POV holder's decision

🔄 Before & After Comparison

❌ LEGACY (Before)

Voting buttons in #panel below TV viewport

  • Limited visibility
  • Small buttons in panel
  • Inconsistent with regular eviction UI
  • No nominee interaction
✅ MODERN (After)

Fullscreen voting overlay + plea system

  • Full-screen focus
  • Large, clear voting interface
  • Matches regular eviction flow
  • Interactive plea system for nominees

📱 Scenario 1: User is POV Holder

When: User wins POV at Final 4

The user has sole power to evict. A fullscreen overlay appears with large, clear voting options.

✓ Implementation: handleFinal4HumanPOVVote() → showFullscreenEvictionVote({ isFinal4: true })

Features:

  • Custom Title: "Cast Your Sole Vote" (instead of generic "Cast Your Vote to Evict")
  • Fullscreen Overlay: Takes over entire screen for maximum visibility
  • Large Nominee Cards: Clear avatars and names
  • Timer Display: Countdown shows remaining decision time
  • Mobile Optimized: Responsive design works on all devices

💬 Scenario 2: User is Nominee

When: User is nominated (not POV, not HOH)

The user can present a plea to the POV holder before they vote, similar to Final 3 HOH plea system.

✓ Implementation: handleFinal4NomineePlea() → FinalPlea.show() with influence calculation

Features:

  • Plea Modal: Reuses Final 3 HOH plea system UI
  • Strategic Messaging: User can craft their case to stay
  • Influence Calculation: Plea affects AI POV holder decision (0-20% swing)
  • Relationship Factor: Stronger relationships = more influence

How Plea Influence Works:

pleaInfluence = 0 to 0.2 (up to 20% decision swing)
evictionScore = (-affinity) + threat - pleaBonus
→ Lower score = less likely to be evicted

👀 Scenario 3: User is HOH (Observer)

When: User is HOH at Final 4

The user observes as the POV holder makes the decision. Shows existing panel UI.

✓ Implementation: renderFinal4EvictionPanel() (existing behavior maintained)

Features:

  • Status Updates: See POV holder's decision progress
  • Nominee Display: Shows who is on the block
  • Power Info: Displays POV holder and HOH info

Flow Logic

    ↓

    ↓
    ├─→ User is POV holder
    │       ↓

    │       ↓

    │       ↓
    │   User selects → finalizeFinal4Eviction()
    │
    ├─→ User is nominee

    │   handleFinal4NomineePlea()
    │       ↓
    │   FinalPlea.show()
    │       ↓
    │   Store influence → AI decides
    │
    └─→ User is HOH (observer)
            ↓
        renderFinal4EvictionPanel()
