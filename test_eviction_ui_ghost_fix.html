🧪 E2E Test: Eviction UI Ghost Fix

Comprehensive test to verify the old voting UI no longer appears after rollout completes

📋 Test Overview

Bug Being Fixed: After submitting a vote via the two-step mobile flow and watching the rollout animation, the old voting UI (red "EVICT" buttons) reappeared under the TV when the overlay dismissed.

Root Cause: When lockHumanVote() called renderLiveVotePanel() after voting, the hasVoted flag was true, causing the two-step condition to fail and fall through to rendering the legacy voting UI.

The Fix: Added an early return in renderLiveVotePanel() that prevents rendering the old UI when the user has already voted via the two-step flow.

  3. Submits the vote (triggers rollout)
  4. Displays rollout animation with all voter reveals
  5. Hides rollout and checks for ghost UI elements
