🔥 Multi-Eviction Cutoff Tie Detection

📖 Test Information

This test demonstrates the cutoff tie detection in multi-evictions.

Cutoff Tie: When nominees outside the top K have the same vote count as the last selected nominee at position K.

Example: In a double eviction (K=2) with votes A:3, B:2, C:2, D:1:
• Top 2 by sort: A(3), B(2)
• Cutoff vote count: 2 (B's count)
• Outside top K: C(2), D(1)
• Tie detected! C has same votes (2) as cutoff (B=2)
• HOH must break tie between B and C
