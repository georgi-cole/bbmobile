E2E Test: Eviction Panel Ghost UI Bug

Reproduces and verifies the fix for the mobile voting UI ghost bug

🎯 Bug Description

Issue: After submitting a vote via the two-step mobile flow and watching the rollout animation, the old voting UI (red "EVICT" buttons) reappears under the TV when the overlay dismisses.

Root Cause: After voting, hasVoted becomes true, causing renderLiveVotePanel() to skip the two-step flow and fall through to render the legacy voting UI.

🧪 End-to-End Test

This test simulates the complete voting flow and checks for ghost UI elements.

Test Steps:
  1. Show the two-step voting choice card
  2. User selects a nominee and clicks "Vote"
  3. Voting overlay appears with red "EVICT" button
  4. User confirms their vote
  5. Rollout overlay shows all votes being cast
  6. Rollout completes and overlay closes
  7. Check: No ghost UI elements should remain visible

Live Vote Panel

This is where the legacy voting UI would appear if the bug exists.
