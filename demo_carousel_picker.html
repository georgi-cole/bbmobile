🎠 Replacement Picker Carousel Demo

Overview

The replacement picker automatically switches between two modes based on viewport width:

  • Mobile (< 768px): Carousel mode - one avatar per slide
  • Desktop (≥ 768px): Grid mode - all nominees at once

Carousel Features

  • Large avatar display with player name
  • Left/right arrow buttons (disable at boundaries)
  • Navigation dots showing position
  • Counter display (e.g., "3 / 7")
  • Touch/swipe gestures (50px threshold)
  • Keyboard navigation: ArrowLeft, ArrowRight, Home, End
  • "Nominate [Name]" action button
  • Full ARIA accessibility support
  • Reduced motion support

Testing Instructions

Carousel Mode:

  • Click left/right arrows to navigate
  • Click navigation dots to jump to specific player
  • Use ArrowLeft/ArrowRight keys to navigate
  • Use Home/End keys to jump to first/last
  • On touch device: Swipe left/right
  • Click "Nominate [Name]" to select

Grid Mode:

  • Click any player tile
  • Confirm screen shows large avatar
  • Click "Back" to return or "OK" to confirm
  • Use arrow keys to navigate between tiles
