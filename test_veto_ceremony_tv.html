Manual Testing Scenarios

Scenario 1: Standard POV (Human, Used)

  1. Start veto ceremony with human POV holder
  2. Verify "Use Power of Veto?" prompt appears in TV
  3. Verify short copy: "Using it removes a nominee. A replacement must be named."
  4. Click "Yes — Use Power of Veto"
  5. Select nominee to save
  6. Verify "Veto Decision" card shows POV holder avatar
  7. Verify "Saved" card shows saved player avatar
  8. Verify "Replacement Required" card shows HOH avatar
  9. Select replacement nominee
  10. Verify risk-swap animation: Stage 1 (both at risk) → Stage 2 (saved becomes safe) → Stage 3 (new replacement at risk)
  11. Verify replacement nominee card appears
  12. Verify adjourn card shows POV holder avatar
  13. Verify no legacy panel appears below TV

Scenario 2: Standard POV (Human, Not Used)

  1. Start veto ceremony with human POV holder
  2. Click "No — Keep Nominations"
  3. Verify "Veto Not Used" card shows POV holder avatar
  4. Verify nominee reaction cards appear (if nominees present)
  5. Verify adjourn card shows POV holder avatar

Scenario 3: Golden POV (Human, Used)

  1. Set goldenPOVChance to 100 in config
  2. Ensure NOT in double/triple eviction week
  3. Start veto ceremony with human POV holder
  4. Verify twist alert: "The Golden Power of Veto is in play..."
  5. Verify "Use Golden POV?" prompt appears in TV
  6. Click "Yes — Use Golden POV"
  7. Select nominee to save
  8. Verify "Replacement Required" shows POV holder avatar (not HOH)
  9. POV holder selects replacement (not HOH)
  10. Verify risk-swap animation

Scenario 4: Diamond POV (Human, Used)

  1. Set diamondPOVChance to 100 in config
  2. Ensure NOT in double/triple eviction week
  3. Start veto ceremony with human POV holder
  4. Verify twist alert: "The Diamond Power of Veto is in play..."
  5. Verify "Use Diamond POV?" prompt appears in TV
  6. Click "Yes — Use Diamond POV"
  7. Select 2 replacement nominees
  8. Verify both old nominees replaced
  9. Verify risk-swap shows transition for multiple nominees

Scenario 5: Multi-Eviction Week Gating

  1. Set goldenPOVChance or diamondPOVChance to 100
  2. Enable double or triple eviction (set __twistMode to 'double' or 'triple')
  3. Start veto ceremony
  4. Verify info card: "Special POV twist suspended for multi-eviction week."
  5. Verify ceremony uses Standard POV flow (not Golden/Diamond)
  6. Verify "Use Power of Veto?" prompt (not Golden/Diamond)

Scenario 6: Same-Pair Validation

  1. Start veto ceremony with human POV holder
  2. Use veto to save one nominee
  3. As HOH, select the SAME player as replacement
  4. Verify error card: "Invalid Replacement" with message about same pair
  5. Verify replacement chooser re-opens
  6. Select different replacement
  7. Verify ceremony continues normally

Scenario 7: Mobile (375px width)

  1. Resize browser to 375px width
  2. Start veto ceremony
  3. Verify all cards fit within TV bounds
  4. Verify buttons wrap properly without overflow
  5. Verify decision copy is readable (2 lines max)
  6. Verify internal scroll works if card is tall

Scenario 8: Reduced Motion

  1. Enable prefers-reduced-motion in browser/OS
  2. Use POV to save a nominee
  3. Verify risk-swap card appears but animations are skipped
  4. Verify game state still commits correctly
  5. Verify replacement nominee receives NOM badge

Scenario 9: GSAP vs Fallback

  1. Test with GSAP loaded: Verify smooth timeline animation
  2. Test without GSAP (or block window.gsap): Verify CSS fallback works
  3. Both should show same visual stages, just different animation method

Scenario 10: AI POV Holder

  1. Start veto ceremony with AI POV holder
  2. Verify AI makes decision automatically
  3. Verify all cards appear in TV
  4. Verify ceremony completes without user interaction

Notes

Testing in Browser: Load index.html, start a new game, advance to veto ceremony phase. Use browser DevTools to inspect elements and verify positioning.

Config Tweaks: Adjust tVetoDec in game config to control decision timer. Set goldenPOVChance/diamondPOVChance to 100 for guaranteed twist testing.

Reduced Motion: In Chrome: DevTools → Rendering → Emulate CSS media feature prefers-reduced-motion. In macOS: System Settings → Accessibility → Display → Reduce motion.

Multi-Eviction Week: Set game.__twistMode = 'double' or 'triple' before ceremony to test gating.
