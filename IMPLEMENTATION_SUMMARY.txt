HOW IT WORKS
================================================================================

1. Page loads → Auto-init block executes
2. Detects mobile UA (iPhone/Android)
3. Sets window.FORCE_MOBILE_ROSTER = true
4. Calls MobileRoster.init() on DOM ready
5. isMobileViewport() checks force flag → returns true
6. activateMobileRoster() → sets body attribute
7. Retry loop ensures activation (max 3 seconds)
8. Mobile roster active with badges and profile sheet

================================================================================
ACTIVATION LOGIC
================================================================================

Mobile roster activates when ANY of these conditions are true:
  1. window.FORCE_MOBILE_ROSTER === true (set for iPhone/Android)
  2. Portrait mode AND width <= 1400px
  3. Mobile UA AND width <= 1600px
  4. Width <= 768px

Desktop remains unchanged:
  - No force flag set
  - Wider viewport
  - Default roster shows
