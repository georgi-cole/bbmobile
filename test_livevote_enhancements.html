🗳️ LiveVoteFullscreen Enhancements Test

✅ New Features Implemented

  • 2-minute voting timer with countdown display (mm:ss)
  • Visual progress ring showing remaining time
  • Auto-vote on timeout (uses autoCastEvictionVote hook)
  • Decorative floating emoji layer (🚪, ❓, ❌, ⛔, 😱)
  • Info (i) button on selected nominee cards
  • Full-screen houseguest profile modal with two tabs
  • Timer pause/resume when profile modal opens/closes
  • Keyboard navigation and accessibility (ESC to close)
  • Configurable timeout via game.cfg.voteTimeoutMs
  • Feature flag for emoji layer via game.cfg.enableFloatingEmojis

🧪 Test Scenarios

Test 1: Timer with Auto-Vote (10 seconds)

Expected: Timer counts down from 00:10. When it reaches 00:00, auto-vote hook is called and overlay closes. Watch the console for auto-vote logs.

Test 2: Full 2-Minute Timer

Expected: Timer counts down from 02:00. Progress ring animates. You can manually vote before timeout.

Test 3: Floating Emoji Layer

Expected: 8 floating emojis animate from bottom to top. They don't block interaction (pointer-events: none). Try clicking through emojis to select nominees.

Test 4: Profile Modal Integration

Expected: Select a nominee to reveal info (i) button. Click it to open profile modal with Basic Info and Game Info tabs. Timer pauses while modal is open. Close modal with X button or ESC key - timer resumes with remaining time.

Test 5: Keyboard Navigation

Expected: Use Tab to navigate between cards. Use Arrow keys to move between nominees. Press Enter/Space to select. Open profile modal and press ESC to close.

Test 6: Testing API Methods

Expected: Opens vote overlay and queries remaining time via LiveVoteFullscreen.getRemainingVoteMs(). Shows current remaining time in console and on screen.

Test 7: Emoji Layer Toggle

Expected: Disables emoji layer via config flag. Next vote overlay should not show floating emojis.

Test 8: Cleanup Verification

Expected: Opens overlay, then calls closeAllVoteUI(). All overlays, timers, and emoji layers removed.
