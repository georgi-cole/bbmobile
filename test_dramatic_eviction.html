🎭 Dramatic Eviction Modal

Test the new dramatic eviction results modal with animations, particles, and optional audio cues. This modal provides a cinematic reveal with vote counting and name reveal effects.

✨ Features

  • Animated Vote Counting: Votes count up with optional tick sound effects
  • Dramatic Name Reveal: Player name appears with scale and glow animation
  • Particle Burst: Visual particle explosion on reveal
  • Accent Colors: Red border/glow for eviction, green for safe
  • Accessibility: Screen reader announcements, keyboard navigation (ESC to close)
  • Reduced Motion: Respects user preferences, disables animations if needed
  • Mobile Friendly: Responsive design works on all screen sizes
Note: Audio files (tick.wav, reveal.wav) are optional. The modal will work without them, but will be silent. To enable audio, add WAV files to /assets/audio/.
Integration: Import the module and call EvictionModal.show({ name, votesFor, votesAgainst, onClose }) wherever eviction results need to be displayed.
