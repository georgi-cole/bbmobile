🔧 Group Action Selection During Scroll - Fix Verification

This test verifies that selected houseguests remain selected when scrolling during group interaction on mobile devices.

Social Intermission

Test Controls

Test Checklist

  • 1. Open modal and select multiple players
  • 2. Scroll within the player picker area
  • 3. Verify selections are preserved after scrolling
  • 4. Long-press on a card while stationary (should toggle group mode)
  • 5. Touch and immediately scroll (should NOT toggle group mode)
  • 6. Verify touch movement > 10px cancels long-press timer
  • 7. Verify all touch events are passive for smooth scrolling

Expected Behavior

  • Tap and hold (stationary): Should trigger long-press after 350ms and toggle group mode
  • Tap and scroll: Should NOT trigger long-press, allows smooth scrolling
  • Movement threshold: > 10px movement cancels long-press
  • Selected state: Preserved in selectedIds Set during scroll
  • Visual feedback: Selected cards maintain blue outline during and after scroll

Implementation Details

  • Touch tracking: Stores initial touch position (touchStartX, touchStartY)
  • Movement detection: touchmove listener calculates delta and sets hasMoved flag
  • Timer cancellation: Movement > 10px clears longPressTimer
  • Selection logic: Only processes tap if !hasMoved && !longPressTriggered
  • Passive listeners: All touch events use { passive: true } for scroll performance
