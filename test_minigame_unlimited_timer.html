🎮 Unlimited Minigame Timer Test (∞)

This test validates that debug mode can launch minigames with an unlimited timer showing the infinity symbol (∞).

Requirements:
  • Timer displays "Time: ∞" instead of countdown
  • No auto-timeout after 60+ seconds
  • Timer has aria-label="Unlimited debug session"
  • Normal debug mode (non-unlimited) still works

Test 1: Unlimited Debug Timer

Launch a minigame with unlimited: true option. Timer should show "Time: ∞" and never expire.

Test 2: Normal Debug Timer (Control)

Launch a minigame with normal timer (30 seconds). Timer should countdown normally.
