🏆 POV Twist Implementation

Golden & Diamond Power of Veto - Visual Documentation

📋 Overview

This implementation adds two new Power of Veto twists with configurable probabilities that enhance the POV holder's power during the ceremony.

🏆 Golden Power of Veto

Default: 5% chance
  • POV holder saves one nominee
  • POV holder (not HOH) picks replacement
  • Cannot nominate: HOH, self, saved player

💎 Diamond Power of Veto

Default: 3% chance
  • Skips save step entirely
  • POV holder replaces BOTH nominees
  • Cannot nominate: HOH, self
  • Priority over Golden if both hit

⚙️ Settings Configuration

Location: Settings → Gameplay → Week twists

// js/settings/registry.js number('goldenPOVChance', 'Golden POV chance (%)', 0, 100, 1), number('diamondPOVChance', 'Diamond POV chance (%)', 0, 100, 1)
// js/ui.config-and-settings.js - DEFAULT_CFG goldenPOVChance: 5, // 5% default diamondPOVChance: 3, // 3% default
📌 Note: Both settings appear in the "Week twists" section alongside Double Eviction, Triple Eviction, Juror Return, and Self-Eviction chances.

🔄 Implementation Flow

1. Twist Decision (Start of POV Competition)

decideVetoTwistForWeek()
  • Rolls once per week when POV competition starts
  • Checks Diamond first (priority)
  • Then checks Golden (independent roll)
  • Result stored in game.activeVetoTwist
  • Persisted via game.__vetoTwistDecidedWeek
↓

2. Twist Announcement

showEventModal with tone: 'twist'
  • Diamond: "Twist alert! The Diamond Power of Veto is in play..."
  • Golden: "Twist alert! The Golden Power of Veto is in play..."
  • Duration: 5 seconds
  • Uses emoji icons (💎✨ for Diamond, 🏆✨ for Golden)
↓

3. POV Competition

  • Runs normally - no changes to competition mechanics
  • Winner determined by scores
  • Twist affects only the ceremony phase
↓

4. Ceremony (Twist-Dependent)

startVetoCeremony() routing
  • Diamond: Routes to handleDiamondPOVCeremony()
  • Golden: Standard flow with isGoldenPOV flag
  • Standard: Normal ceremony with HOH picking replacement

🎯 Priority & Edge Cases

⚠️ Priority Rule:
If both Diamond and Golden twists hit in the same week (rare but possible with high percentages), Diamond takes precedence. Only one twist can be active per week.
📌 Persistence:
The twist decision is made once per week when POV competition starts and persists through the entire ceremony. The game checks game.__vetoTwistDecidedWeek === game.week to prevent re-rolling.
🔒 Eligibility Rules:
• HOH cannot be nominated (all ceremony types)
• POV holder cannot be nominated (all ceremony types)
• Saved nominee cannot be re-nominated (Standard & Golden only)
• Diamond POV has no saved nominee (skips save step entirely)
