🏋️ Hold The Wall Minigame Test Harness

Testing endurance minigame with no phase timer

📋 Test Instructions

Purpose: This test harness simulates the Hold The Wall minigame behavior without relying on the full game infrastructure. It validates:
  • Phase timer is disabled when the minigame starts
  • Players can drop and receive 0 points
  • Results are computed from non-dropped players only
  • Results are published exactly once
  • Phase advances to results when returning to main screen

✅ Expected Behavior Checklist

Verify these behaviors during testing:
  • ✓ When "Start Game" is clicked, phase timer should be paused (check console)
  • ✓ When a player drops, they should be removed from holding list
  • ✓ Dropped players should emit "minigame.playerDropped" event with points: 0
  • ✓ Winners should only include players who haven't dropped
  • ✓ "Return to Main Screen" should publish results exactly once
  • ✓ Phase should advance to "results" after return to main screen
  • ✓ Multiple returns to main screen should not re-publish results
