🎮 PLAY Button No Intro/Loading - Sanity Check

Test Description

This test verifies that pressing the PLAY button advances immediately to the gameplay UI without showing the loading screen (eye icon) or intro audience-reactions sequence.

Expected Behavior:

  • No avatar preloading progress bar should display

  • No reality-TV style intro or classic dual-card intro should display
  • The game phase should transition from opening to intermission within ~500ms
  • Avatars should load on-demand as they are rendered
