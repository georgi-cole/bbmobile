# TV Inline Cards Screenshots

This directory contains visual verification screenshots for the unified inline TV overlay card design.

## Screenshots

The following screenshots should be generated by running the Playwright test:

```bash
npx playwright test tests/inline-cards-screenshot.spec.js --project=chromium
```

### Expected Screenshots

1. **inline-card-basic.png** - Basic text card with `.tv-inline-card` styling
   - Shows semi-transparent blur background
   - Themed colors based on `--theme-primary`
   - Readable text with auto-adjusted contrast

2. **inline-card-decision.png** - Decision card with action buttons
   - Contains primary and secondary buttons
   - Dialog role for accessibility
   - ESC key dismissal support

3. **inline-card-avatars.png** - Card with player avatars
   - Displays player avatars above content
   - Arrow separator between actors and subjects
   - Responsive layout for multiple avatars

## Manual Verification

If automated screenshots cannot be generated, manually verify by:

1. Open `test_tv_inline_cards.html` in a browser
2. Click each test button to display card types
3. Verify:
   - `.tv-inline-card` class is present (check green indicator)
   - Backdrop blur is applied (visible glass effect)
   - ARIA attributes are set (role, aria-live, tabindex)
   - Legacy classes preserved (revealCard, diaryRoomCard)
   - Theme colors applied with proper contrast
