📝 Test Description

This test simulates the race condition that occurs when startLiveVote() is called before nominee data is available in the game state.

✅ Test Scenarios

  • Test 1 - Immediate: Nominees are set before calling startLiveVote (no race).
  • Test 2 - Delayed: startLiveVote is called first, nominees set after delay (race condition).
  • Test 3 - Timeout: Nominees are never set, should use heuristic fallback.

✅ Acceptance Criteria

  • Test 1 should emit phase:eviction:start immediately with correct nominees
  • Test 2 should wait for nominees, then emit phase:eviction:start after they appear
  • Test 3 should timeout after 2s and use heuristic fallback to infer nominees
  • All tests should log the nominee source (where nominees were found)
  • No "No valid nominees found" error in normal scenarios
