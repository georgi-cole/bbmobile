Toolbar Scroll Test

This page tests the horizontally scrollable toolbar implementation:

  • Resize window to mobile width (320px, 375px, 414px)
  • Verify toolbar scrolls horizontally without wrapping
  • Check fade gradients appear at edges when scrollable
  • Test keyboard navigation (Tab to focus buttons, Left/Right arrows to scroll)
  • Confirm all buttons remain accessible

This toolbar has many buttons to test scrolling on narrow viewports.

Accessibility Tests

  • Press Tab key to navigate through buttons - focused button should scroll into view
  • When focused on toolbar, press Left/Right arrow keys to scroll
  • All buttons should remain keyboard accessible
  • Fade overlays should not block clicks (pointer-events: none)

Visual Tests

  1. Resize to 320px width - toolbar should scroll, no wrapping
  2. Resize to 375px width (iPhone) - toolbar should scroll
  3. Resize to 414px width (iPhone Pro Max) - may scroll depending on buttons
  4. Resize to 768px+ width - should not scroll (all buttons visible)
