# Social Maneuvers vs Legacy Memory Popup - Comparison Guide

## Overview

This document explains the differences between the NEW Social Maneuvers summary system and the LEGACY "Memories" popup, and how to test both systems.

## The Two Systems

### 1. LEGACY "Memories" Popup (OLD)

**What it is:**
- The original social phase summary shown at the end of social phases
- Created by `showCard()` function in `social.js`
- Called from `generateSocialSummary()`
- Shows simple text-based summary: alliances formed, rivalries, romance/bromance

**Pros:**
- ✅ Simple and easy to understand
- ✅ Quick overview of major relationship changes
- ✅ "Details" button provides more information

**Cons:**
- ❌ Overlaps with new Social Maneuvers summary
- ❌ Not phase-aware (could show at wrong times)
- ❌ Limited data - only shows major relationship milestones
- ❌ No action tracking or resource spending information

**Example content:**
```
Social Update
━━━━━━━━━━━━━━━
• Strong alliance: Alice & Bob
• Rivalry emerged: Charlie vs Diana
• Romance/Bromance: You & Alice
```

### 2. NEW Social Maneuvers Summary (NEW)

**What it is:**
- Comprehensive end-of-phase summary with detailed statistics
- Generated by `generatePhaseSummary()` in `social-maneuvers.js`
- Displayed by `showSummaryPanel()` with detailed breakdown
- Triggered by `onSocialPhaseEnd()`

**Pros:**
- ✅ Tracks ALL actions taken during the phase
- ✅ Shows energy and information spent per player
- ✅ Lists relationship changes with affinity deltas
- ✅ Identifies new alliances and rivalries with thresholds
- ✅ "View Details" button shows comprehensive breakdown
- ✅ "Copy JSON" button for data export
- ✅ Respects phase gating (only shows when appropriate)

**Cons:**
- ❌ More complex UI (but more informative)
- ❌ Requires session tracking to be properly initialized

## The Issue: Legacy Popup Overlapping New Summary

**Problem:**
When Social Maneuvers is enabled, BOTH summaries were showing up:
1. The new Social Maneuvers detailed summary card
2. The old Legacy "Memories" popup

This caused:
- Visual clutter and confusion
- Overlapping UI elements
- Inconsistent information (legacy shows less detail)
- User doesn't know which to trust

**Solution Implemented:**
- Added `shouldShowLegacyMemories()` guard function
- When `Social Maneuvers.isEnabled()` returns true, legacy popup is suppressed
- Guard checks both `SocialManeuvers.isEnabled()` and `USE_SOCIAL_MANEUVERS` flag
- Legacy popup only shows when Social Maneuvers is disabled (backwards compatibility)

## Addressing the User's Concern: "Shows 0 to everything"

The user mentioned that the new summary shows "0 to everything" and doesn't update values properly. Here's why this might happen and how to fix it:

### Possible Causes:

1. **Session Not Initialized:**
   - `onSocialPhaseStart()` must be called to initialize session tracking
   - Without this, `game.__socialManeuversSession` doesn't exist
   - Result: All values show as 0

2. **Actions Not Tracked:**
   - Actions must be executed via `SocialManeuvers.executeAction()`
   - Direct affinity manipulation bypasses tracking
   - Result: Actions count = 0, energy spent = 0

3. **Summary Called Too Early:**
   - If `onSocialPhaseEnd()` is called before actions are taken
   - Session data will be empty
   - Result: Everything shows 0

4. **Testing with Mock Data:**
   - If testing manually without proper game setup
   - Session tracking might not be initialized
   - Result: Missing data

### How to Verify It Works:

1. **Check session initialization:**
   ```javascript
   console.log(window.game.__socialManeuversSession);
   // Should show: { startTime, week, actionsThisPhase: [], energySpent: Map, ... }
   ```

2. **Check after an action:**
   ```javascript
   // Execute an action
   window.SocialManeuvers.executeAction(1, 2, 'strategize', []);
   
   // Check session
   console.log(window.game.__socialManeuversSession.actionsThisPhase.length); // Should be > 0
   console.log(window.game.__socialManeuversSession.energySpent.get(1)); // Should be > 0
   ```

3. **Check summary data:**
   ```javascript
   // Generate summary
   window.SocialManeuvers.onSocialPhaseEnd();
   
   // Check summary
   const summary = window.game.__latestSocialSummary;
   console.log(summary.actions.total); // Should match actions taken
   console.log(summary.resources.energySpent); // Should show spent amounts
   ```

### Expected Behavior:

**After Proper Setup:**
- Actions count: Shows number of actions executed
- Energy spent: Shows total energy spent (sum of action costs)
- Information spent: Shows information spent (for actions with info costs)
- Relationship changes: Shows affinity deltas for each interaction

## The Value of the New System

While the legacy popup is simpler, the new Social Maneuvers summary provides:

1. **Action-level Detail:** See exactly what actions were taken and their outcomes
2. **Resource Tracking:** Know how much energy and information was spent
3. **Precise Affinity Changes:** See exact affinity deltas, not just "alliance formed"
4. **Threshold Detection:** Automatically identifies when alliances/rivalries form
5. **Data Export:** Can export full session data as JSON for analysis
6. **Better Integration:** Works seamlessly with the Socialize mobile UI
