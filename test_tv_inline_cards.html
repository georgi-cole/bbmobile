TV Inline Cards Test Page

Test Controls

Keyboard Testing

• Press ESC to dismiss a card
• Press TAB to navigate between buttons
• Press ENTER or SPACE on focused button to activate

Accessibility Testing

• Cards have ARIA roles (dialog with actions, status without)
• Focus ring appears on :focus-visible
• Reduced motion can be tested via DevTools: Rendering > Emulate CSS media feature > prefers-reduced-motion

Visual Features

• Semi-transparent background with backdrop-filter: blur(6px)
• Theme-aware coloring from --theme-primary and --theme-on-primary
• Smooth entry animation (scale + translateY)
• No borders except focus ring
