🧪 Game Over Exit → Play Flow Tests

📋 Test Objectives

This test validates the complete user flow when evicted pre-jury:

  1. User is evicted before making jury
  2. Game Over modal appears
  3. Game progression stops (no week modal appears)
  4. User clicks "Exit" button
  5. IntroScreen appears with reset state
  6. User clicks "Play" button
  7. New game starts successfully

This addresses the bug: "Play button does not properly trigger a new game" after Game Over exit

Test 1: Game Progression Stops When Game Over Modal Queued

Verifies that postEvictionRouting() returns early when __showGameOverModal is set

Test 2: IntroScreen.reset() Called on Exit

Verifies that Exit button calls IntroScreen.reset() to clear state

Test 3: Play Button Works After Exit

Simulates full flow: Eviction → Game Over → Exit → Play button click

Test 4: No Week Modal When Game Over Queued

Verifies that proceedNextWeek() is NOT called when game is over

Test 5: Full Integration Test

End-to-end test simulating the complete user journey
