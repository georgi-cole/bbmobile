🎮 Per-Minigame Duration Config - Interactive Demo

A comprehensive implementation of configurable minigame challenge timers with pause/resume functionality, completion animations, and graceful edge case handling.

📋 Overview

This feature adds a centralized configuration for minigame challenge duration (default: 3 minutes / 180 seconds) that can be adjusted by admins through the settings UI. The phase timer pauses when a challenge starts and resumes when it completes, ensuring accurate time tracking.

🎯 Key Features

⚙️ Configurable Duration

Admin-only setting in Gameplay tab. Range: 30-600 seconds. Default: 180 seconds (3 minutes).

⏸️ Timer Pause/Resume

Phase timer pauses when Play button is pressed and resumes after minigame completion or cancellation.

🎉 Completion Animations

Shows success message with score. Displays confetti effect if new record is achieved.

🛡️ Edge Case Handling

Gracefully handles timeout, early finish, abandon, and phase end scenarios.

🔄 Competition Flow

📺
Step 1: Instructions Instructions card appears in TV viewport with Play button
▶️
Step 2: Play Button Pressed Phase timer pauses, challenge timer starts (uses config duration or phase timer)
🎮
Step 3: Minigame Overlay Fullscreen overlay with timer countdown and close button
✅
Step 4: Completion Shows animation (confetti if new record), displays score, then closes overlay
▶️
Step 5: Resume Phase timer resumes from where it paused, returns to main view

✨ Animation States

🎉
New Record!
Confetti animation + score display
✅

⏱️
Time's Up!
Auto-submits score (0 on timeout)
⚠️
Phase Ended
Challenge canceled gracefully

📝 Configuration Code

The configuration is stored in the centralized settings system:

const DEFAULT_CFG = { // ... other settings ... minigameDuration: 180 // Default: 3 minutes };

Accessible in settings UI under: Gameplay → Minigame settings → Challenge timer duration

🧪 Edge Cases Handled

⏰ Timer Expiration

Disables interaction, shows "Time's Up!" message, auto-submits after 1.5s delay.

✅ Early Finish

Shows completion animation, resumes phase timer, normal score submission.

❌ Manual Abandon

Confirms with user, closes overlay without submission, resumes phase timer.

🔄 Phase Change

Shows "Phase Ended" message, cancels challenge, cleans up overlay automatically.
