Alibi Grid — Logic Puzzle

Four suspects, four attribute categories. Use the clues to deduce which value belongs to each suspect. Tap a cell to cycle: Yes → No → Unknown. When ready, press "Make Accusation". You have one free retry; a hint reveals a single correct cell at the cost of points.

Mobile-first: drag-scroll the grid if needed. No external assets used.
