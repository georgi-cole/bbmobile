📋 Manual Testing Instructions

1. Visual Testing: Click each button to verify modal appearance matches specifications.
2. Interaction Testing: Test dismissal by clicking anywhere on the modal, clicking the overlay, or pressing Escape.
3. Motion Testing: Use browser DevTools to emulate "prefers-reduced-motion" and verify animations are disabled.
4. Accessibility Testing: Use keyboard navigation to ensure focus trap works correctly.
5. Contrast Testing: Verify text is readable against all background colors.
