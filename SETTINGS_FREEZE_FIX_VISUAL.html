🔧 Settings Before Play - Freeze Bug Fix

Comprehensive fix for initialization race condition

❌ Problem: Race Condition Causing Freeze

User Experience: Game freezes on "Week 1 – Season Premiere" screen when Settings is opened before Play button

1. Open Settings
Config reinitialized
→
2. Press Play
buildCast() called
→
3. Players Created
Deferred task executes
→
4. Players CLEARED!
buildCast() called again 💥

Root Cause:

  • buildCast() called twice in quick succession
  • Second call clears players array: g.players.length = 0
  • Config.ensureGameCfg() creates new objects every time
  • Race condition → MobileRoster timeout → freeze

✅ Solution: Idempotent Initialization

Fix 1: Make buildCastInternal() Idempotent

// NEW: Check if players already initialized
if(g.players && g.players.length > 0 && g.players[0].id){
console.info('[buildCast] Players already initialized, skipping');
return; // Skip rebuild!
}
g.players.length = 0; // Only clear if rebuilding

Fix 2: Make Config.ensureGameCfg() Idempotent

// NEW: Check if config already valid
if(g.cfg && Object.keys(g.cfg).length >= DEFAULT_CFG_SIZE * 0.8){
return g.cfg; // Return existing config!
}
// Only recreate if missing/corrupted

Config already valid ✓
→
2. Press Play
buildCast() defers ✓
→
3. Players Created
First buildCast() ✓
→
4. Players Preserved
Second call skipped ✓
