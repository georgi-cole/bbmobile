⏩ FFWD Startup State Fix - Test Suite

This test validates that FFWD state is properly reset at startup and uses window.game as single source of truth.

Test 1: Boot-time State Reset

Verify that FFWD state is reset to defaults when state.js loads.

Test 2: Single Source of Truth (window.game)

Verify that all FFWD operations read/write window.game consistently.

Test 3: activateFastForward() Behavior

Verify that activateFastForward() correctly sets flags and prevents re-entry.

Test 4: deactivateFastForward() Behavior

Verify that deactivateFastForward() correctly resets flags.

Test 5: Import Safety Reset

Verify that importing a save with FFWD active resets the state.

Test 6: normalizeDuration() Consistency

Verify that normalizeDuration() reads from window.game.
