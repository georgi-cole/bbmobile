Guest Mode Intro Skip & Season Increment Test

Test Environment

Test 1: Guest Mode Detection & Intro Skip

This test verifies that when a user selects "Play as Guest", the intro is skipped and the game proceeds directly without playing theatrical sequences.

Test 2: Season Increment for Profile

This test verifies that when a profile completes a game and clicks "Start New Season", the season number increments by +1 and persists to storage.

Test 3: Season Normalization

This test verifies that profiles with missing or invalid season values are normalized to 1.

Test 4: Guest Mode Never Increments Season

This test verifies that incrementSeason() is a no-op when in guest mode.

Test 5: Integration Test - startGame() Flow

This test verifies that startGame() calls the correct functions based on guest mode status.
