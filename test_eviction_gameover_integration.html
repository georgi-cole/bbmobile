🧪 Eviction Game Over Integration Tests

📋 Test Objectives

This test harness validates the Game Over modal logic across all eviction flows:

  • Single Eviction: Human evicted pre-jury in standard vote
  • Multi-Eviction: Human evicted pre-jury in double/triple eviction
  • Self-Eviction: Human self-evicts pre-jury

Each test mocks the necessary functions and asserts that:

  1. g.__showGameOverModal is set correctly
  2. GameOverModal.show() is called with correct parameters
  3. Fallback to global.showCard() works if module unavailable

Test 1: Single Eviction Pre-Jury

Simulates human player evicted at 10th place (7-person jury, jury starts at 9th)

Test 2: Multi-Eviction Pre-Jury

Simulates double eviction where human is one of two evicted at 12th place

Test 3: Self-Eviction Pre-Jury

Simulates human self-eviction at 11th place - should show Game Over modal

Test 4: Modal Loading Resilience

Tests polling/retry when GameOverModal not immediately available

Test 5: Fallback to showCard

Tests fallback when GameOverModal never loads

Test 6: Human Makes Jury (No Modal)

Verifies modal is NOT shown when human makes jury (9th place with 7-person jury)
