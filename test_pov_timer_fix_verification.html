🛡️ POV Timer Fix Verification

Fix Summary

Issue Fixed: Redundant idle/wait timers in POV flow causing empty waiting periods
Root Cause: Multiple setTimeout calls without proper tracking and cleanup, resulting in redundant waits between results → winner display → veto choice card.

Changes Made

  1. Added Timer Tracking - New fields __vetoInlineWinnerTimer and __vetoPostRevealTimer to track all active timers
  2. Created clearAllVetoTimers() - Central function to clear all veto-related timers
  3. Added POV_INLINE_WINNER_DURATION_MS - Configurable constant (3000ms default) for inline winner display duration
  4. Modified handlePostVetoReveal() - Shows inline winner UI for human POV winner using TVInlineStatus
  5. Timer Cleanup on Phase Transitions - All timers cleared when phase changes to prevent stale callbacks

Flow Comparison

❌ BEFORE (with redundant timers):

1. POV competition completes → finishVetoComp()
2. Results shown fullscreen (1000ms)
3. Timer 1: Wait for results dismiss (1100ms setTimeout)
4. handlePostVetoReveal() called
5. Timer 2: Idle wait (??ms) ← REDUNDANT
6. Timer 3: Another wait (??ms) ← REDUNDANT
7. startVetoCeremony() shows veto decision
Total time: ~3-5s with empty waits

✅ AFTER (human POV winner):

1. POV competition completes → finishVetoComp()
2. clearAllVetoTimers() - Clean slate
3. Results shown fullscreen (1000ms)
4. __vetoPostRevealTimer: handlePostVetoReveal() (1100ms) ← TRACKED
5. Inline winner UI shows immediately: "You won POV! 🛡️"
6. __vetoInlineWinnerTimer: Wait for inline winner (3000ms) ← TRACKED
7. clearAllVetoTimers() → startVetoCeremony()
8. Veto decision shows immediately
Total time: 4.1s (1s results + 3s winner + 0.1s transition)

✅ AFTER (spectator/AI winner):

1. POV competition completes → finishVetoComp()
2. clearAllVetoTimers() - Clean slate
3. Results shown fullscreen (1000ms)
4. __vetoPostRevealTimer: handlePostVetoReveal() (1100ms) ← TRACKED
5. startVetoCeremony() called immediately (no inline winner)
6. Ceremony proceeds normally
Total time: 1.1s (unchanged from before)
