🛡️ POV Timer Fix Verification

Fix Summary

Issue Fixed: Redundant idle/wait timers in POV flow causing empty waiting periods
Root Cause: Multiple setTimeout calls without proper tracking and cleanup, resulting in redundant waits between results → winner display → veto choice card.

Changes Made

  1. Added __skipInlineWinner Flag - New flag set when human wins POV to enable fast-path flow
  2. Instant Results Dismiss for Human - Results modal uses autoDismissMs=0 when human wins
  3. Modified finishVetoComp() - Determines human winner and sets __skipInlineWinner flag
  4. Modified handlePostVetoReveal() - Respects __skipInlineWinner flag to skip 3s inline winner wait
  5. Fast-Path Flow - Human winners immediately see veto decision card (no main-screen timer)
  6. Preserved Non-Human Behavior - Spectators/AI winners still see 1s results display

Flow Comparison

❌ BEFORE (with redundant timers):

1. POV competition completes → finishVetoComp()
2. Results shown fullscreen (1000ms)
3. Timer 1: Wait for results dismiss (1100ms setTimeout)
4. handlePostVetoReveal() called
5. Return to main screen with status banner "You won POV!" (3000ms) ← REDUNDANT WAIT
6. startVetoCeremony() shows veto decision
Total time: ~5.1s with redundant main-screen wait

✅ AFTER (human POV winner - FAST PATH):

1. POV competition completes → finishVetoComp()
2. Determine human won POV → set __skipInlineWinner = true
3. clearAllVetoTimers() - Clean slate
4. Results shown with autoDismissMs=0 (instant dismiss) ← NO WAIT
5. __vetoPostRevealTimer: handlePostVetoReveal() (50ms) ← MINIMAL
6. Skip inline winner UI (no main-screen timer)
7. startVetoCeremony() shows veto decision IMMEDIATELY
Total time: ~50ms (instant flow: results → winner → ceremony)

✅ AFTER (spectator/AI winner):

1. POV competition completes → finishVetoComp()
2. __skipInlineWinner = false (non-human winner)
3. clearAllVetoTimers() - Clean slate
4. Results shown fullscreen (1000ms)
5. __vetoPostRevealTimer: handlePostVetoReveal() (1100ms) ← TRACKED
6. startVetoCeremony() called immediately (no inline winner)
7. Ceremony proceeds normally
Total time: 1.1s (unchanged from before)

Key Improvements

  • ✓ Human POV winner: Fast-path enabled with __skipInlineWinner flag
  • ✓ Human winner sees instant transition: results → ceremony (no main-screen timer)
  • ✓ Results modal autoDismissMs=0 for human winners (instant)
  • ✓ All timers tracked in game state fields
  • ✓ clearAllVetoTimers() called on phase transitions
  • ✓ No idle/empty waiting periods for human winners
  • ✓ Phase guards prevent stale callbacks
  • ✓ Configurable timing constants
  • ✓ Spectator flow unchanged (1s results display, no regressions)
